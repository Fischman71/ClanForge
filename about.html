About

One person, one clan, one app.

I'm Kye — OogaBooga in-game. I lead a small clan that's rebuilding after a quiet stretch, and ClanForge started because running it was eating way more time than it should: chasing donations, tracking stats, planning wars, sorting out roles. I built the tool I wanted for myself, then figured other leaders were dealing with the same thing.

I'd love for ClanForge to be free, but running the backend and the AI tools costs real money — that's what Pro pays for. The bigger goal isn't just saving leaders time, though. Tools like Base Markup and the Weekly Digest are built to get more members actually engaged, so the whole clan benefits — not just whoever's running it.

How to reach me

  • Discord — questions, bug reports, feature requests. Join and I'll hand you 30 days of Pro, no card, no email.
  • GitHub — file an issue for bugs.
  • Email — clanforgeapp@gmail.com, for anything that doesn't fit the above.

Things I'll never do

  • Never sell user data.
  • Never add ads.
  • Never add gameplay automation.
  • Never use Supercell trademarks.
