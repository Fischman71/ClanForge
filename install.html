Why isn't this on the Play Store?

Google's review process for clan tools that read game data is slow and unpredictable for a solo dev. Sideloading means a fix or a new feature ships the day it's ready, not whenever a review queue clears.

Is this safe?

Every release is signed with the same key — check the fingerprint above against the GitHub Release page before you install. ClanForge has no analytics and no trackers, and your clan data stays on your phone unless you turn on a Pro hosted feature.

Troubleshooting

Chrome says this file is unsafe.

Chrome flags every sideloaded APK this way, not just ClanForge's. Tap the download notification, then "⋮" → Download anyway (or "Keep" on the warning that follows).

My phone won't let me install from this source.

Android blocks installs from unknown sources by default. When you open the APK, tap Settings on the prompt, enable Allow from this source for your browser, then go back and open the file again.

Install was blocked by Play Protect.

Play Protect scans every sideloaded app, signed or not. Tap More details → Install anyway. ClanForge doesn't ask for any permission beyond what's listed in the guide.

I'm on iOS.

There's no iOS build, and no timeline for one. Join the Discord if you want to hear first if that changes.

Still stuck? Ask the Help Desk.

ClanForge tells you in-app when a new version is out. Updates are also posted in Discord — full notes on the changelog.
