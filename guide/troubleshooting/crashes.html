Crashes & how to report

ClanForge collects no crash analytics or telemetry — so if something breaks, a quick report is the only way it gets fixed. Discord for a fast back-and-forth, GitHub Issues if you'd rather file it properly.

Open Settings → Links for both — Discord and the GitHub Issues page are one tap away. In Discord, just describe what happened; for GitHub, a short title plus what you were doing is enough to start.

Tip: The most useful report is: what you tapped right before it happened, your Android version, and a screenshot if anything appeared on screen. Without crash analytics, those details are the entire debugging trail — even "it just closed while I was opening War Planner" narrows things down a lot.

Not every red message is a crash. In-app alerts like "Couldn't load clan" usually mean a network hiccup or the shared cache mid-refresh — try again in a moment first. A hard crash, where the app closes entirely, is always worth reporting regardless of how minor it seemed.
