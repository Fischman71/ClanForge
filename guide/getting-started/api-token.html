Your API Token

ClanForge asks for your in-game API Token once, to confirm a player tag is actually yours. Here's exactly where to find it in Clash of Clans, and what ClanForge does — and doesn't — do with it.

In Clash of Clans, open Settings (the gear icon, top right), then More Settings. Scroll down to API Token and tap it to reveal the code.

Copy that code into ClanForge's verification prompt. ClanForge sends it once to Supercell's official verification endpoint — the same check Supercell provides for any third-party tool — to confirm the tag belongs to whoever's holding the phone.

Tip: If verification fails, go back to Settings → More Settings in Clash of Clans and tap the API Token field again. It can take a moment to generate, and occasionally needs refreshing.

After that one check, ClanForge doesn't reuse this token. All ongoing data — your stats, your clan's roster, war info — is fetched server-side through ClanForge's own access, not yours. The token is never stored as a way to access your account later.

It's also worth knowing what this token isn't: it's not your Supercell ID password, and ClanForge will never ask for that. The API Token only proves you can see your own in-game settings — nothing more.
