Install ClanForge

ClanForge is a direct APK download from clanforge.cc — never the Play Store. This article is the short version. For the full download button, screenshots, and the signing-key fingerprint to verify your download, head to the Install page.

Android blocks installs from outside the Play Store by default. That's a standard Android setting, not a sign anything's wrong — you'll allow it once, for ClanForge specifically.

  1. Download the APK from the Install page.
  2. Allow your browser to install apps when prompted.
  3. Open the downloaded file and tap Install.

Tip: If Chrome flags the file as "unsafe," that's the standard sideload warning, not a problem with ClanForge. The Install page explains what it means and how to proceed.

Full steps, screenshots, and the fingerprint to verify your download against are on the Install page.

Once it's running, ClanForge tells you in-app when an update is ready — releases are also posted in Discord. See the Changelog for what's shipped recently.
